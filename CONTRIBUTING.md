# Contributing

Thank you for improving DemoTenant Switchboard.

1. Create a focused branch.
2. Run `python -m pip install -e ".[dev]"`.
3. Add or update tests for behavior changes.
4. Run `python scripts/verify.py`.
5. Open a pull request with the motivation, risk, and verification results.

Do not commit secrets, real customer data, generated local caches, or browser artifacts.
